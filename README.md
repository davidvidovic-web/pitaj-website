# pitaj-website

Marketing website for [pitaj.io](https://pitaj.io), built with **Astro** and **Tailwind CSS**.

Faithful reproduction of the modern Chatbase design system:
- High-performance Astro static build
- Typography: **Geist** sans + **Proza Display** italic serif accents
- Pixel-perfect layout with 1240px container grid, subtle borders, and micro-interactions
- Responsive desktop navigation with mega dropdowns and mobile drawer
- 6 Complete Routes:
  - `/` — Homepage (Hero with live agent simulation, 3 Agent types showcase, 4-step Lifecycle, Bento Product Suite, Omnichannel deployment, Testimonial quotes, Security badges, Industry verticals, and CTA banner)
  - `/pricing` — Interactive monthly / annual toggle (-20%), 4 tiers (Hobby, Standard, Pro, Enterprise), add-ons, and FAQ accordion
  - `/enterprise` — Enterprise capabilities, VPC/compliance overview, and demo lead capture form
  - `/security` — Trust & Security center with SOC 2 Type II, GDPR, HIPAA, and data governance principles
  - `/customers` — Case studies from leading brands (Opal, Aplazo, Jumia, Thotis Media, etc.)
  - `/features/product-overview` — Deep-dive platform overview (Procedures, Widgets, Helpdesk, Backstage)

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```
